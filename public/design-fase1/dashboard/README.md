# Home / Hoje

Tela principal do app **doniq** (390×844). Representa o momento de entrada do representante — "Conte como foi. Confira o relatório. Siga o dia."

## Elementos principais

- **Header:** wordmark `doniq` com `q` no gradiente violet→blue→cyan, avatar do usuário.
- **Hero:** número grande do dia (12/24 visitas) em display-xl + legenda curta. Sem label decorativa acima.
- **Flowline do dia:** barra gradiente com 3 nós (Falar · Revisar · Feito). Mostra o ritmo do dia, não decoração.
- **Quick actions:** dois cards — "Contar uma visita" (primário, com gradiente) e "Iniciar rota".
- **Próximas visitas:** lista de cards com nome do cliente, empresa/cidade, chip de status (pendente/ao vivo/concluída) e timestamp + distância.
- **FAB centralizado acima do tab bar:** gradiente completo, ação primária "Contar uma visita".
- **Tab bar:** 4 tabs (Hoje · Rota · CRM · Conta), label só na ativa.
